# 數字轉國字大寫工具

一個使用 Vite + Vue.js + Tailwind CSS 建立的現代化數字轉國字貨幣表示工具。

## 功能特色

- ✨ **支援多種貨幣**：新台幣（NT$）、人民幣（¥）、港元（HK$）
- 🔢 **大數字支援**：最高可轉換到**佰億**（99,999,999,999）
- 📝 **多種輸出格式**：
  - 數字大寫完整描述
  - 填空格式（台灣銀行表單常用）
  - 表格顯示（大寫/小寫）
- 🎨 **現代化 UI**：使用 Tailwind CSS 打造漂亮的漸層背景和響應式設計
- ⚡ **即時轉換**：輸入數字後即時顯示轉換結果

## 快速開始

### 安裝依賴

```bash
npm install
```

### 開發模式

```bash
npm run dev
```
